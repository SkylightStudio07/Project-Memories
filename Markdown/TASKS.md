# TASKS

## 구현 원칙

### 작업 전 확인 사항

* 기존 구현을 먼저 분석하고 재사용 가능한 구조를 우선 활용한다.
* 동일한 기능이 이미 존재한다면 새로운 시스템을 만들지 않고 기존 시스템을 확장한다.
* 필요 이상의 리팩토링은 지양한다.
* 현재 정상적으로 동작하는 기능은 변경하지 않는다.
* 새로운 Manager나 시스템은 반드시 필요한 경우에만 추가한다.
* 구현 완료 후 기존 기능이 정상적으로 동작하는지 확인한다.

---

# 구현 항목

## 1. 대응 판정 로직 변경

### 목표

기존의 로직에서는 아무 입력도 하지 않거나 공격할 수 있는 상황에서 공격하지 않는 등 최적의 대응을 하지 않으면 체력이 깎이고 있음.
이 부분을 전면 변경할 것.

### 요구 사항

* 최선의 대응인가?에 대한 판단 제거. -> 이에 따른 불이익은 없도록 한다.
* 기존의 배틀 규칙에 따라서만 체력 감소 판정할 것
* 가드 상태에서만 공격 무효화 시킬 수 있으며 이외의 쉼/공격 상태에서는 받은 공격의 데미지를 그대로 받는다.
* 자신이 공격 상태이면서 상대가 가드 상태가 아닐 때에만 상대에게 데미지를 줄 수 있음. (적이나 플레이어나 동일)

---

## 2. 레이저 연출

### 목표

공격 시 해당 캐릭터로부터 상대 캐릭터까지로 뻗어나가는 레이저를 연출한다.

### 요구 사항

#### 레이저 표현

* 캐릭터가 공격 행동을 실시할 때 레이저 발사되는 연출할 것.
* 레이저는 공격한 캐릭터로부터 상대로 쏘아질 것.
* 레이저 발사되는 위치를 조정할 수 있는 Transform용 게임 오브젝트를 만들어서 이 위치로부터 상대로 쏘아지게 할 것.
* 레이저 발사 위치인 Transform 오브젝트의 위치 오프셋은 적 데이터에서 조정할 수 있게 할 것.

# 완료 보고

모든 구현이 완료되면 다음 내용을 함께 보고한다.

1. 수정한 파일 목록
2. 각 파일에서 수행한 변경 사항
3. 기존 구조를 어떻게 재사용했는지
4. 새로 추가한 클래스 또는 컴포넌트(있는 경우)
5. 추후 개선하면 좋을 사항
