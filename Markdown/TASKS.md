### Flip 연출 개선

**목표**

* 동일한 스프라이트가 연속으로 사용되는 경우에도 캐릭터가 실제로 행동했다는 피드백을 제공한다.

**현재 문제**

* `방어 → 방어 → 방어`처럼 같은 스프라이트가 연속으로 표시되면 Sprite Flip 효과가 발생하지 않아, 플레이어 입장에서는 행동이 실행되지 않은 것처럼 보인다.

**요구사항**

* 이전 행동과 동일한 스프라이트를 사용하는 경우에도 Flip 연출이 항상 재생되도록 수정한다.
* Flip 효과는 스프라이트 변경 여부와 관계없이 **행동(Action)이 실행될 때마다** 발생해야 한다.
* 동일한 행동이 연속으로 이어져도 매번 시각적인 반응이 발생하여, 캐릭터가 실제로 해당 행동을 수행했다는 피드백을 제공한다.

**예시**

* `방어 → 방어 → 방어 → 방어`

  * 현재: 첫 번째만 Flip, 이후에는 변화 없음.
  * 목표: 네 번 모두 Flip 효과가 재생되어 매번 방어 동작이 실행된다는 것을 명확하게 보여준다.

**구현 시 고려사항**

* Flip 효과의 트리거를 **스프라이트 변경 이벤트**가 아닌 **행동 실행 이벤트** 기준으로 분리한다.
* 동일 스프라이트 재사용 여부와 관계없이 Flip 애니메이션은 독립적으로 재생될 수 있도록 구조를 개선한다.

이것도 작업 요청 형태로 정리하면 아래처럼 전달하면 된다.

### 차징 상태 연출 추가

**목표**

* 차징 상태임을 플레이어가 한눈에 인식할 수 있도록 시각적인 오오라 연출을 추가한다.

**요구사항**

* 캐릭터가 `Charging` 상태에 진입하면 캐릭터 주변에 파티클 오오라를 생성한다.
* 오오라는 차징이 종료될 때까지 유지되고, 차징이 끝나면 자연스럽게 사라진다.
* 오오라의 색상은 해당 캐릭터의 **레이저 색상과 동일한 컬러**를 사용하여, 차징 중인 공격이 어떤 속성/색상의 레이저인지 직관적으로 연결되도록 한다.

**연출 방향**

* 현재 단계에서는 간단한 Particle System으로 구현한다.
* 캐릭터를 중심으로 은은하게 에너지가 퍼지는 느낌의 오오라면 충분하다.
* 과도하게 화려하기보다는 "현재 차징 중이다"라는 상태를 명확하게 전달하는 것을 우선한다.

**구현 시 고려사항**

* 차징 시작 시 파티클을 활성화하고, 차징 종료 또는 차징이 취소될 경우 즉시 비활성화한다.
* 파티클 색상은 레이저 색상을 참조하도록 하여, 이후 레이저 색상이 변경되더라도 자동으로 동일한 색상을 사용할 수 있도록 구조를 구성한다.
* 추후 Glow, Bloom, Distortion 등의 이펙트를 추가하기 쉽도록 오오라 연출을 독립적인 컴포넌트(예: `ChargeAuraEffect`)로 분리하는 것을 권장한다.

**기대 효과**

* 플레이어가 위험한 레이저 공격을 준비 중이라는 것을 즉시 인지할 수 있다.
* 레이저와 동일한 색상을 사용하여 차징 → 발사의 연결성이 강화되고, 전투의 가독성과 연출 퀄리티가 향상된다.
