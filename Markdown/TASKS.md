# TASKS

## 구현 원칙

### 작업 전 확인 사항

* 기존 구현을 먼저 분석하고 재사용 가능한 구조를 우선 활용한다.
* 동일한 기능이 이미 존재한다면 새로운 시스템을 만들지 않고 기존 시스템을 확장한다.
* 필요 이상의 리팩토링은 지양한다.
* 현재 정상적으로 동작하는 기능은 변경하지 않는다.

---

# 높은 우선순위

## 1. Sprite 전환 애니메이션

### 목표

스프라이트가 변경될 때마다 종이를 넘기는(Flip) 듯한 전환 효과를 재생한다.

### 구현 방식

* Unity Animator State Machine을 사용하지 않는다.
* 모든 애니메이션은 코드에서 직접 제어한다.
* 각 상태 스프라이트는 1프레임 이미지이므로 스프라이트 교체 방식으로 구현한다.
* 추후 다른 스프라이트 변경에도 재사용할 수 있도록 공통 함수 또는 컴포넌트로 구현하는 것을 권장한다.

---

## 2. Attack Animation

### 목표

* 공격 시 Attack 스프라이트로 전환한다.
* Attack 이미지는 1프레임만 사용한다.

---

## 3. Defense Animation

### 목표

* 방어 시 Defense 스프라이트로 전환한다.
* Defense 이미지는 1프레임만 사용한다.

---

## 4. Hit Animation

### 목표

피격 시 타격감을 표현한다.

### 포함 요소

* Damage Flash
* 짧은 흔들림(Shake)
* 피격 스프라이트 전환(필요 시)

---

# 중간 우선순위

## Enemy Queue UI

* 적의 다음 행동 4개를 순서대로 표시한다.
* 행동 공개 박자에 맞춰 슬롯을 하나씩 채운다.

---

## Player Queue UI

* 플레이어 입력 결과를 4박 동안 순서대로 표시한다.
* 입력 성공 시 해당 방향 아이콘을 슬롯에 표시한다.

---

# 낮은 우선순위

## Score

* 적을 빠르게 처치할수록 높은 점수
* 강한 적일수록 추가 점수

---

## Combo

* 연속 성공 입력 보너스
* 추후 밸런스 조정 가능

---

## Effect

* 공격 이펙트
* 방어 이펙트
* UI 이펙트
* 추가 연출

---

## Camera Shake

* 공격 적중 시
* 강한 공격 시
* 추후 Effect 시스템과 연동
