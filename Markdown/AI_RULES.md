# AI Rules

## 최우선 원칙

이미 구현되어 있는 시스템을 최대한 활용한다.

기존 클래스가 존재한다면
새로운 클래스를 만드는 것보다
확장하거나 리팩토링하는 방향을 우선 고려한다.

---

## 절대 하지 말 것

- 기존 동작을 변경하지 않는다.
- 기존 Public API를 함부로 수정하지 않는다.
- 사용되지 않는 것처럼 보여도 삭제하지 않는다.
- Inspector 세팅이 필요한 컴포넌트를 마음대로 교체하지 않는다.
- Scene 구조를 변경하지 않는다.

---

## 허용되는 작업

- 기존 클래스에 기능 추가
- private 함수 추가
- helper 함수 추가
- enum 추가
- ScriptableObject 확장
- UI 연결

---

## 코드 스타일

- 작은 클래스 선호
- 함수 하나는 하나의 역할만 수행
- 매직넘버 사용 금지
- enum 적극 활용
- Inspector 노출 최소화

---

## 작업 방식

항상

1. 기존 구조 조사
2. 재사용 가능한 코드 탐색
3. 최소 수정으로 구현

순으로 진행한다.

새로운 시스템은 마지막 선택이다.
