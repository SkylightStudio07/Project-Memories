넥슨 게임잼 '재밌넥' 진행 중이야..

GDD-Draft.md 파일에 일차적으로 기획을 진행한 내용이 작성되어 있어.

나(user}는 게임업체 취직용 유니티 포트폴리오가 이미 몇 개 있고, 유니티를 일반적으로 사용할 수 있어.

현재 기획서에 따라 DAY 1 내용을 개발해야 하며, 개발의 용이를 위해 해당 아키텍쳐를 일반적으로 따르는 것이 좋음.

현재 유니티 CLI 관련하여 스킬이 여러 개 등록됐으니 확인하기 바람.

1. 데이터 컨테이너(비 Monovihaviour 스크립트 - EnemyData 등)
2. 데이터 기반 SO(Enemy 등)
3. 매니저

* 해당 사항을 자체적인 .md 파일에 기록해두고 개발을 진행할 것.
* 만약 개발을 진행 중 기획이 명확하지 않은 부분이 있으면 개발을 중단하고, {{user}}에게 질문할 것.
* 한꺼번에 전부 수행하려고 하지 말 것. 한 번에 한 모듈(Enemy 등), 혹은 그보다 작은 단위로 진행.
* 개발 진행중 특기할 사항 및 진행 상황 [[노션 개발 진척 페이지](https://www.notion.so/Beat-Memories-3a7b5f9bddef8059a2bfce0b5a3bff73?source=copy_link)]에 작성할 것.
* 플레이어 및 적은 단순 스프라이트, 십자키 관련 UI는 Canvas위에서 처리할 것.
* 절차적 생성으로 구현되는 적 공격의 패턴 시스템은 난수 독립성과 재현성을 보장해야 함.
* 유니티 CLI Skill을 이용해 하이어라키와 인스펙터까지 전부 작업할 것.
* 출력문의 마지막에는 {{user}}이 해당 진척사항과 관련되어 무슨 태스크를 수행해야 하는지 명시할 것.
